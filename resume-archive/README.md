# Resume archive

Superseded versions of the CV, one dated folder per replacement. The live copy
is always `Atharva_Kulkarni_Resume.pdf` at the repository root — that path is
linked from the site and from submitted job applications, so it must not move.

| Archived | What it was |
|---|---|
| `2026-09-13/` | Pre-rewrite version. No website, no SEC0/SEC1, no TryHackMe standing, and no Security Tooling section — the toolkit, CyberChef integration, agent framework and knowledge base were absent entirely. |

## Replacing the live resume

1. Move the current root PDF into `resume-archive/<today>/`
2. Copy the new export to the repository root under the same filename
3. Commit both moves together so the root path is never missing

The filename never changes. Anything already linking to
`atharvaxsecurity.com/Atharva_Kulkarni_Resume.pdf` keeps working.
